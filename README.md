# Agenda de Contactos (CLI)

Projeto desenvolvido como parte do desafio prático do módulo de Introdução ao Python da Rocketseat.

## 📋 Funcionalidades

- **Adicionar contacto**: Registo de nome, telefone, e-mail e marcação de favorito.
- **Visualizar contactos**: Listagem de todos os contactos registados com indicação de favorito.
- **Editar contacto**: Atualização dos dados de um contacto existente.
- **Marcar/Desmarcar favorito**: Gestão rápida do estado de destaque do contacto.
- **Listar favoritos**: Filtro dedicado apenas aos contactos marcados como favoritos.
- **Apagar contacto**: Remoção de registos da agenda.
